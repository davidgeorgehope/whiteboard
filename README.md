# Whiteboard

Point a webcam at a piece of paper and get a live digital whiteboard.

Two panes:

- **Live board** — the camera feed, digitized in real time in the browser (OpenCV.js): the sheet of paper is detected and perspective-corrected, shadows and uneven lighting are removed, and ink contrast is boosted. Use **Present** to full-screen it while you talk.
- **AI whiteboard** — a beautified version generated by a persistent Cursor agent: it transcribes the handwriting letter by letter, writes a rendering spec, then drives its image generation tool to draw a polished digital whiteboard. It refreshes automatically a moment after you stop writing (or via **Beautify now**). Each refresh is a fresh drawing, so the layout may shift between passes.

## Setup

```bash
npm install
cp .env.example .env   # add your CURSOR_API_KEY (cursor.com/dashboard/integrations)
npm run dev
```

Open http://localhost:5173, pick your camera, and point it at the paper so all four corners are visible. The board outline turns green in the corner preview once it locks.

The live pane works without an API key; only the AI pane needs one.

## How it works

- `web/` — Vite + TypeScript frontend. OpenCV.js (vendored at `web/public/opencv.js`) finds the largest 4-sided contour, warps it flat, then each pixel is divided by a blurred background estimate to cancel shadows before a contrast stretch.
- `server/` — Express + `@cursor/sdk`. One persistent local agent is created on first use; each beautify pass sends the cleaned snapshot inline as an image. The agent transcribes the text first (a vision LLM reads handwriting far more reliably than an image model), then generates the whiteboard image with the transcription pinned in the prompt and the snapshot as a layout reference. The PNG is returned to the browser as a data URL.
- Auto-refresh is motion-gated: a pass fires ~1.6s after writing motion stops, with requests serialized and coalesced so only the latest board state is processed.

## Notes

- Beautify latency is typically 1–3 minutes for a dense board (transcription + image generation). Set `CURSOR_MODEL` in `.env` to pin a specific (vision-capable) model.
- Fix the camera and paper in place for best results; hit **Re-detect board** if either moves.
- Anker C200 users: run `scripts/camera-tune.sh` after plugging in the camera. It sets manual focus and zoom over UVC (the camera ships with autofocus off and focus parked for conference distance, which blurs an overhead rig). Override with `FOCUS=nnn ZOOM=nnn` if your stand height changes.
